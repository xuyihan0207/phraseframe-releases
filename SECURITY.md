# Security Policy

Security fixes are provided for the most recent published beta.

Use GitHub private vulnerability reporting under this repository's
**Security** tab. Include the affected version, minimal reproduction steps,
expected impact, and any suggested mitigation.

Do not disclose a vulnerability in a public issue before a fix is available.
If private vulnerability reporting is unavailable, contact the repository
owner privately through their GitHub profile and provide only enough
information to establish a secure reporting channel.

Reports involving access outside the selected workspace, unsafe external link
or media handling, installer integrity, or data loss should be treated as
security-sensitive.

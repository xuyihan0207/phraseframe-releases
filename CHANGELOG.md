# Changelog

## 0.1.0-beta.1 — Pending publication

Initial free proprietary Windows beta.

### Included

- PhraseFrame name and modular-card application icon.
- Local-first `.topic` and `.media` workspaces.
- Multi-tab modular rich-text cards.
- Notes, comments, reusable layouts, trash recovery, and local full-text
  search.
- Images, tables, local media cards, and external media references.
- NSIS and MSI Windows x64 installers.

### Known limitations

- Installers are not code-signed.
- Multiple application instances must not edit the same workspace.
- Automatic updates are not included.
- The beta is licensed for personal evaluation, learning, and note-taking.

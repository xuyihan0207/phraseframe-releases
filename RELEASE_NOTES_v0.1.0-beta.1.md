# PhraseFrame v0.1.0-beta.1

First public Windows x64 beta.

This is the first public build and uses the PhraseFrame name, modular-card
icon, application identifier, and license throughout.

## Download

- Choose `PhraseFrame_0.1.0_x64-setup.exe` for a normal install.
- Choose the `.msi` package for managed deployment.
- Verify both installers with `SHA256SUMS.txt`.
- Read `EULA.txt` before installation.

## Important beta notices

- This is free proprietary beta software; source code is not distributed.
- Installers are not code-signed, so Windows may show an unknown-publisher
  warning.
- Do not run multiple application instances against the same workspace.
- Keep independent backups of important workspaces.
- Uninstalling the application does not delete a user-selected workspace.

# Privacy Notice

Last updated: July 24, 2026

PhraseFrame Free Beta is a local-first desktop application.

- Workspaces, cards, notes, comments, and imported assets are stored in folders
  selected by the user.
- Rebuildable search indexes and workspace metadata are stored inside the
  workspace.
- Interface preferences and the Microsoft Edge WebView2 profile are stored in
  the application's local data directory.
- The Free Beta does not require an account and includes no application
  telemetry, advertising analytics, or application-operated cloud sync.
- The application does not automatically upload workspace content or crash
  reports.

If a user voluntarily submits a bug report, they control the information they
provide and should remove private notes, personal paths, and real media.

The optional NSIS cleanup checkbox removes application settings and the
WebView cache. It does not delete user-selected workspaces.

This notice will be updated before any future feature begins collecting or
transmitting additional data.
